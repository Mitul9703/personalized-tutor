# Frontend

React app for the personalized tutor. Chat on one side, the slide artifact
panel with version history on the other.

Planned stack: React, Vite, TypeScript, Tailwind, shadcn/ui, Framer Motion.
The full app is scaffolded in the frontend phase of the build.

It talks to the backend only over the HTTP API. The API base url is set in
`.env` (see `.env.example`).
